# 💬 Chat App with Fiber and React

A simple chat application built using the **Fiber** web framework in Go for the backend and **React** for the frontend. This app is a work-in-progress and will include WebSocket-based real-time messaging soon.

## 🚀 Features (Planned & In Progress)

- ✅ React frontend with Vite
- ✅ Go backend with Fiber
- 🔄 Real-time messaging with WebSockets (in development)
- 🧪 Modular structure for easy updates and scalability

## 🛠️ Tech Stack

**Frontend:**

- React
- Vite
- CSS Modules

**Backend:**

- Go (Golang)
- Fiber (Express-style Go web framework)
- (Coming soon) Gorilla WebSocket
